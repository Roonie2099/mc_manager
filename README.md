Prepare before using:
1. Make a folder with whatever name you want(prefer naming it "mc_manager") and take all of those file/folder above put it in the big folder just made
2. After put all those file/folder in the big folder, put the big folder into the folder "game" in minecraft folder
3. Now move all your mods into the "mods_storage" folder in the big folder
4. Everything is perfect now( you can make a shorcut for "z_mod_control.py" in the deckstop if you want )

How to use:
 Run the "z_mod_control.py" by double click on it ( better if you have shortcut in deckstop )

Feature:
1. You can add/remove mods from using or add/change instances* and manage all of it
2. You can add always_mods* too

*instance is a group of mods you want to use it all together
*always_mods is mods that you always want to use
